Comment les rangs sont-ils calculés ?

Un scénario obtient le plus haut rang dont le seuil est atteint. Pour les moyennes, les paliers valent 1 point pour Bronze, 2 pour Silver, 3 pour Gold, 4 pour Platinum et 5 pour Diamond. La progression est interpolée entre deux seuils ; sous Bronze, elle va de 0 à 1. Chaque scénario est plafonné à 5 points.

Le rang d’une catégorie est la partie entière de la moyenne de ses trois scénarios. Le rang global suit la même règle sur les douze scénarios. Cette règle locale est explicite et ne prétend pas reproduire l’algorithme interne de KovaaK’s. Ces rangs sont personnels, pas des rangs Voltaic officiels.

Les résultats sont importés depuis les fichiers locaux KovaaK’s. Les seuils et anciens records se modifient dans data.js. Recharge ensuite la page. L’historique reste dans ce profil Chrome : sauvegarde-le avant de supprimer les données du navigateur ou de changer d’ordinateur.
